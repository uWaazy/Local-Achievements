### New
- Update notifications: when a new version is published on GitHub, the plugin shows the installed and new version numbers and what changed, and can download, verify (SHA-256) and install it with one click. If anything fails, your current version is kept.
- Choose how to be told about updates (window, Playnite notification only, or no checks) and use "Check for updates now" in the plugin settings. Available in English, Portuguese and Spanish.
- A notification confirms the new version after Playnite restarts.
- Updating to this version has to be done manually once; from here on, updates can be installed from inside Playnite.
